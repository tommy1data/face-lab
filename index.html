What Face Lab Can Do

Six powerful modules working in harmony — all running on your GPU via WebAssembly.

Face Detection
MediaPipe BlazeFace dual-backend (short + full range) with simulated Haar benchmark. Detects multiple faces at <50ms latency.
BlazeFace GPU Dual Backend
Real-Time Recognition
Register faces once with 3–5 samples, then get live identification using 200-dimensional cosine similarity embeddings.
Embeddings Cosine Sim localStorage
Emotion Detection
Classify 6 core emotional states from facial geometry — happy, sad, angry, surprised, disgusted, neutral — in real time.
6 Emotions Real-Time Landmarks
Multi-Person Tracking
Track multiple faces simultaneously in a single frame. Each face gets individual ID assignment and live emotion + match overlay.
Multi-Face Tracking Overlay
Anti-Spoofing
Liveness detection using blink ratio and face symmetry analysis — flags photos, screens, and static faces as spoofing attempts.

One-click PNG capture with annotations overlaid. Export PID tracking logs as CSV for offline analysis in Excel or Python.

How it works
MediaPipe extracts a 300-dim face descriptor per frame using 100 aligned landmarks. Top-K cosine similarity is computed against enrolled samples. The closest match above the threshold is shown.

Tips: register 5–10 samples from different angles for best accuracy. Descriptors auto-update on high-confidence matches. Visit history is logged and exportable as CSV.
